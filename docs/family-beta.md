# Family Beta (0.7)

기준: feature/v0.7-family-beta. 기존 Family Alpha staging만 사용하며 production 및 main은 변경하지 않습니다.

## 구현

- 연결 상태 표시, 실패 시 2/4/8/16초 backoff, 최신 snapshot 복구. 이동은 계속 가능하고 서버 권위 행동은 복구 전 제한합니다. 정상 polling은 응답 완료 후 약 1초입니다. 요청 제한 시간은 8초입니다.
- 같은 맵 가족의 걷기/대기/방향/도구 동작과 닉네임 표시. 서버가 승인한 도구 action은 2.5초 후 만료하며 ID별 한 번만 재생합니다.
- 접속 중 가족 전원 수면 동의, 취소, 12초 presence TTL 및 세션 변경에 따른 투표 정리. 혼자면 즉시 다음 날로 진행합니다.
- 로비 관리: 닉네임, 구성원과 접속 여부, 일반 구성원 나가기, 방장 초대 코드 재발급/삭제. 방장은 그냥 나갈 수 없습니다. 삭제는 FK cascade로 members/state/presence를 정리합니다.
- 햇살감자/하트딸기/아침당근, 씨앗 선택, 공유 crop/item 정의 및 서버 가격 검증. 상세 수치는 [spring-crops.md](spring-crops.md).
- 접을 수 있는 가족 패널: 접속 인원, 같은 맵 여부, 수면 상태, 연결 상태, 초대 코드 복사.

DB migration은 추가하지 않습니다. 기존 family_state JSON과 presence pose JSON을 확장합니다. SaveData v4, 맵 편집기 JSON schema, 기존 player PNG와 fallback을 유지합니다. 날짜/시간/밭/자금은 공유하며 인벤토리는 개인별입니다.

## 자동 검증 범위

`npm run test:regression`은 SQLite 기반 D1 대역으로 A/B 방 참가와 상태 공유, revision 경쟁, 도구 action 만료, 수면 합의/취소/TTL/세션 교체, 초대 코드 갱신과 기존 코드 거부, 닉네임/나가기/삭제 cascade, 신규 작물 전체 생명주기 및 서버 가격 검증을 수행합니다. 싱글플레이 저장과 맵 편집기 회귀 검사 및 PNG/fallback 검사도 포함합니다. UI 검사는 서버 렌더링과 로직 검사이며 실제 가족 계정 두 개의 브라우저 동시 플레이를 대신하지 않습니다.

## 실제 가족 테스트 순서

1. staging에서 A/B가 서로 다른 ChatGPT 계정과 기기로 로그인합니다. A가 테스트 농장을 만들고 B가 복사한 8자리 코드로 참가합니다.
2. 같은 맵에서 이동/정지/방향과 괭이/물뿌리개/씨앗/손 동작을 서로 확인합니다. 다른 맵으로 이동하면 상대 캐릭터가 숨겨져야 합니다.
3. A가 밭을 갈고 선택한 씨앗을 심으면 B에게 반영되는지, B의 물주기가 A에게 반영되는지 확인합니다.
4. A만 수면을 선택하면 날짜가 유지되고 대기 상태가 표시되어야 합니다. 취소 후 다시 A/B 모두 동의하면 날짜와 작물 성장이 함께 바뀌어야 합니다.
5. B를 종료하고 약 12초 TTL 이후 남은 접속자 기준으로 수면 투표가 처리되는지 확인합니다. 일반 정상 polling 환경에서는 화면 갱신까지 추가 polling 시간이 필요할 수 있습니다.
6. 한 기기의 네트워크를 잠시 끊습니다. 이동은 가능하고 농사/구매/판매는 제한되어야 합니다. 복구 시 자동으로 최신 상태와 연결 표시가 돌아오는지 확인합니다.
7. 세 신규 작물을 각각 구매/심기/물주기/성장/수확/판매합니다. 수확물은 수확한 사람의 인벤토리, 판매금은 공동 자금에 반영되어야 합니다.
8. 로비 관리에서 닉네임 변경, 초대 코드 재발급 및 이전 코드 거부, 일반 구성원 나가기를 확인합니다. 방장 나가기는 거부되어야 합니다. 마지막에 버려도 되는 테스트 농장만 삭제합니다.
9. 가족 모드를 종료하고 기존 혼자 하기 저장과 맵 편집기를 확인합니다. 모바일 세로/가로에서 접힌 패널, 퀵바, 조이스틱이 가려지지 않는지도 확인합니다.

## 남은 제한

- polling 기반이므로 짧은 연속 도구 동작은 일부 생략될 수 있습니다. 실시간 네트워크 엔진, 오프라인 행동 병합, 소유권 이전/강퇴는 없습니다.
- 씨앗 선택은 현재 플레이 세션에 유지되고 재진입 시 기본 씨앗으로 돌아갑니다.
- 실제 기기 입력감, 모바일 배치, 두 실제 계정의 인증/동시 플레이는 위 수동 검증이 필요합니다.
