# 지우네 농장 2.0 Smoke Test

테스트 전 최신 `feature/v2.0-integration-stabilization`을 사용하고, 새 싱글 저장과 기존 저장을 각각 준비한다. Family는 서로 다른 계정의 두 브라우저 또는 두 실제 기기로 확인한다.

자동 사전 검증: `npm run install:ci` → `npm run test:regression` → `npm run test:integration` → `npm run build`

## PC 싱글 플레이

- [ ] 새 게임에서 이동, 모든 warp, 침대 복귀가 가능하다.
- [ ] 씨앗 심기 → 물주기 → 잠자기 → 수확 → 판매 → 씨앗 구매가 이어진다.
- [ ] 요정의 숲에서 재료를 얻고 제작·도끼 강화·곡괭이 해금을 완료한다.
- [ ] 가방, 제작대, 보관함을 열고 수량 이동 후 ESC와 닫기 버튼으로 나온다.
- [ ] 목재 가공기를 배치하고 재료 투입 → 시간 경과 → 결과 수령 → 회수한다.
- [ ] 농지를 확장하고 작업 창고와 닭장을 안전한 위치에 건설한다.
- [ ] 광산 1~5층 채광과 각 층 탈출, 낚싯대 선택과 연못 낚시가 된다.
- [ ] 닭 구입 → 먹이 → 쓰다듬기 → 다음 날 달걀 수령·판매가 된다.
- [ ] NPC 대화 → 의뢰 → 선물 → 관계 이벤트 후 일반 대화가 계속된다.
- [ ] 저장 후 새로고침해 인벤토리, 진행도, 배치물, 건물, 동물 상태를 복구한다.

## 모바일 싱글 플레이

- [ ] 실제 Android/iOS에서 joystick, 행동 버튼, 7개 도구 quickbar가 눌린다.
- [ ] HUD와 safe-area가 노치·주소창·홈 표시줄에 잘리지 않는다.
- [ ] Inventory, Storage, Machine, Building, Fishing, Ranch, NPC/Event 패널을 닫을 수 있다.
- [ ] 배치·건설 시 터치 대상과 가능/불가 피드백이 명확하다.

## Family A/B

- [ ] 같은 날짜·날씨·돈·농장·숲·광산·보관함·기계·건물·확장·동물이 보인다.
- [ ] A/B의 가방, 체력, 스킬, 도구, 낚시, NPC·의뢰·선물·이벤트 진행은 섞이지 않는다.
- [ ] 같은 작물/보관함/기계/광산/건설/확장/동물/달걀을 동시에 조작해 한 요청만 성공한다.
- [ ] A는 농장, B는 광산 다른 층에 있을 때 서로가 잘못 렌더링되지 않는다.
- [ ] 각자 reconnect 후 공동 상태와 개인 상태가 최신 서버 snapshot으로 복구된다.
- [ ] 두 사람이 잠자기에 동의했을 때만 날짜가 한 번 증가하고 개인 체력이 각각 회복된다.

## 날짜·저장 경계

- [ ] 봄/여름/가을 28일 다음은 다음 계절 1일, 겨울 28일 다음은 2년차 봄 1일이다.
- [ ] 다음 날 작물, 비, 체력, 숲, 광산, 기계, 동물, 낚시 cast가 각각 한 번만 처리된다.
- [ ] v1~v4 저장과 일부 optional 필드가 손상된 저장이 정상 데이터 손실 없이 열린다.

## Map Editor

- [ ] PC/모바일 편집, terrain/object/Inspector, Undo/Redo, Import/Export가 된다.
- [ ] test play와 draft sync가 게임 SaveData 또는 runtime 진행 상태를 섞지 않는다.

실제 터치감, 모바일 safe-area, 두 기기 네트워크 지연·reconnect 체감, 픽셀 그래픽·애니메이션 품질은 자동 테스트 결과와 별도로 기록한다.
