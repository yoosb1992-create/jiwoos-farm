# v2.8 플레이어 UI와 캐릭터 외형

시작 기준: `0bfe58a0904f00b4f5857f0cc8e9dfeea8b59e39` / `feature/v2.7-world-editor-2`.

## 사용 방법

- 즐겨찾기는 오른쪽 단축슬롯 바로 위에 열립니다. 설정의 세로형/펼쳐보기를 유지하며, 낮은 가로 화면에서는 스크롤 가능한 임시 행으로 표시합니다. 아래 1·2·3·★, 위 4·5·6·7 저장 구조는 같습니다.
- 플레이어 메뉴에는 가방, 캐릭터 꾸미기, 퀘스트, 지역 지도, 주민, 달력, 도감, 설정, 조작 배치, 농장 및 가족이 있습니다. 동물/정원/잠자기/농장 관리/연결 복구/로그아웃은 농장 및 가족에 있습니다.
- 설정에서 개발자 모드를 켜면 월드 편집기, 보간 설정, Network HUD와 접속 진단을 볼 수 있습니다. 끄면 개발자 메뉴와 HUD가 숨겨집니다.
- 새 플레이어는 접속 화면의 캐릭터 꾸미기를 사용합니다. 기존 플레이어는 메뉴에서 외형을 변경합니다. 저장 전 옵션은 미리보기에만 적용됩니다. 취소와 기본 외형 복원, 네 방향, 대기/걷기/달리기 미리보기를 제공합니다.
- 성별 2형, 키 3단계, 헤어 8종(기본 포함), 헤어 색상 7종, 상의 7종, 하의 5종, 신발 5종을 제공합니다. 모든 헤어는 양쪽 체형에서 사용할 수 있습니다.
- 다른 기기는 기존 기기의 농장 및 가족 → 개인 이어하기 코드 복사 후, 접속 화면의 ‘다른 기기의 내 플레이어 이어하기’에 입력합니다. 가족 초대 코드와 달리 개인 세션 자격증명이므로 본인만 사용합니다. 기존 90일 세션 만료 정책이 적용됩니다.

## 데이터와 권한

- 외형 v1은 기존 `World.members[playerId].appearance` JSON에 저장됩니다. DB 테이블 교체, 초기화, 별도 DB가 필요하지 않습니다.
- 서버에서 외형 항목과 허용 값을 검사하며, 기존 행동 영수증/트랜잭션으로 저장한 뒤 개인 상태와 Colyseus 플레이어 appearance 필드를 전송합니다. 다른 멤버의 외형·가방·농장을 덮어쓰지 않습니다.
- 외형이 없는 저장본은 원본 농부 프리셋으로 읽습니다. 키는 렌더 스케일만 변경합니다. 이동·충돌·타일·도구 사용 범위는 변하지 않습니다.
- 기존 농장 소유자 세션은 새 설계도 작성 권한을 가집니다. 기존 설계도 편집 토큰은 해당 설계도의 편집 권한을 유지합니다. `/api/developer`가 서버에서 이를 확인합니다. 표시 설정이나 클라이언트 isOwner 값은 서버 권한이 아닙니다.
- 새 설계도 생성은 인증된 농장 소유자에게 제한합니다. 기존 설계도 저장/게시의 토큰 및 revision 검증, 농장 이름/삭제의 소유자 검증은 유지합니다. 새 고정 비밀번호나 전역 관리자 권한은 없습니다.

## 렌더링과 CI

- 원본 48프레임 아틀라스와 기존 도구/운반 포즈를 재사용합니다. 의상 마스크와 헤어를 화면에서 합성하고 사용된 외형의 텍스처만 캐시합니다. 대기·걷기·달리기·모든 도구·보관함 운반에 같은 합성기를 사용합니다. 도구 손잡이는 키에 맞춘 실제 손 좌표를 따라갑니다.
- 원본 프리셋은 기존 텍스처를 그대로 사용합니다. 스프라이트 조합별 파일을 대량 생성하지 않습니다.
- 기존 household 실패는 닫힌 dialog에 남은 data-panel 속성을 열린 패널로 간주했습니다. 닫힐 때 속성을 정리하고 실제 visible 상태를 검사합니다. 새 아침 처리는 이전 날짜에 열린 잠자리 패널만 닫습니다.
- 터치 이동 후에는 서버가 새 정지 입력을 처리했음을 확인한 뒤 방향 전환과 도구 사용을 진행합니다. 이전 이동 입력이 남아 앞칸 판정이 달라지던 문제를 보완하며 이동 속도·충돌·사용 범위는 유지합니다.
- 브라우저 시험용 설계도는 실제 편집 권한으로 생성하고, 게시 후 선택을 초기화 코드가 덮어쓰지 않도록 했습니다. 확장 자연물·터치 및 운영 빌드 브라우저 검사도 실패를 무시하지 않는 필수 CI 단계입니다.
- 검증: Typecheck/Build, 기존 단위/통합/배포 검사, household PC·휴대전화, quickbar 위치·재접속, 편집기, 외형 초안/저장/취소/서버 권한/두 클라이언트 동기화/새 기기 복구, 헤어·방향·도구 손잡이/발 위치 검사. 외형 및 권한 통합 검사는 CI의 실제 PostgreSQL 환경에서도 실행됩니다.
- Railway `jiwoos-farm-v2-5` 기존 Frontend/Backend/Postgres를 사용합니다. 대기 중인 Check Suites 설정 2건은 적용하지 않습니다. 마을·집·신규 NPC 콘텐츠는 추가하지 않습니다.
