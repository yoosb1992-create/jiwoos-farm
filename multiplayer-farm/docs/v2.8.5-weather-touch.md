# v2.8.5 — 강우와 터치 조작

기준: `9309d07908ce7a924b169583daf71b920d73791c`, `feature/v2.7-world-editor-2`.

## 날씨·저장 호환성

기존 `World.weather`/`FarmState.weather`는 `clear`/`rain`/`snow` 의미를 유지한다. 새 선택적 `World.weatherPlan`은 일자, 강우 종류, 시작·종료 분, 전환 길이, 결정적 seed, 풍향(동쪽 0°, 시계 방향), 풍속(m/s), 돌풍 세기를 보관한다. 방 입장 시 이전 저장 데이터의 당일 `rain`은 종일 일반 비로 해석한다. 다음 날부터 새 계획을 생성한다. PostgreSQL JSON 저장·백업/복원 형식과 기존 버전/리스/트랜잭션은 유지하며 DB 마이그레이션은 없다.

| 종류 | 길이 × 크기 / 두께 | 낙하 속도 px/s | 상대 밀도 | 햇빛 감소 | 천둥 / 번개 확률 |
|---|---|---:|---:|---:|---:|
| 가랑비 | 7 × 0.7 / 0.7 | 135 | 0.65 | 12% | 0 / 0 |
| 일반 비 | 15 × 1 / 1.1 | 350 | 1.65 | 30% | 4.5% / 0.6% |
| 소나기 | 25 × 1.3 / 1.65 | 650 | 2.8 | 53% | 32% / 11% |
| 폭풍우 | 33 × 1.65 / 2.2 | 900 | 4.2 | 73% | 68% / 49% |

확률은 비가 충분히 내리는 **80 게임 분 간격**에 한 번 평가한다(기본 속도 약 40초). 번개는 천둥 사건 중 일부이므로 소리만 들리는 상황이 존재한다. 모든 가족 구성원이 동일한 계획과 사건을 수신한다. 사건은 기존 schema patch에 실리며 별도의 30Hz 날씨 패킷은 없다. 과거 사건은 재접속·페이지 복원 시 재생하지 않는다.

소나기는 12:00~16:00 사이 시작해 160~259 게임 분 지속한다. 양 끝 12 게임 분 동안 강도/채광이 변하고, 렌더러가 추가로 보간한다. 깊은 밤/달빛/기존 광원은 보존한다. 실내와 광산은 강우·번개·천둥을 차단한다. 고정 typed array + 하나의 Graphics batch를 사용하며 화면과 프레임 시간에 따라 최대 휴대전화 200개, 큰 화면 280개로 제한한다. 바람은 빗방울 각도에만 영향을 준다.

천둥은 FarmAudio의 저역 잡음 합성으로 생성하며 전체 음량/음소거를 따른다. 번개는 짧은 지그재그 줄기와 최대 6.5%의 단일 밝기 변화로 표시한다. 설정의 보통/줄이기/끄기는 기기에 저장되며 reduced-motion 사용자는 기본 줄이기 모드다. 번개가 있는 사건의 천둥은 450~1099ms 뒤 들린다. 편집기 미리보기 선택은 로컬 그림과 격리된 샌드박스만 바꾼다.

## 수분·터치

강우 시작 시 기존 저장 직렬 큐/리스로 노출된 soil/crop을 한 번 적신다. 수확·다년생 수확·파종은 기존 watered를 보존하며 강우 중 새 경작지도 젖는다. 비가 그쳐도 즉시 마르지 않고 다음 날의 기존 규칙을 따른다.

빈 땅 터치는 이동만 한다. 경작/파종/나무 심기/회수/운반은 행동 버튼 등 명시적 조작을 사용한다. 마른 경작지는 물뿌리개 선택 시 이동 후 물을 준다. 성숙 작물은 손으로 수확한다. 나무·그루터기·가지=도끼, 바위=곡괭이, 제거 가능한 풀=낫, 채집물/드롭=손이다. 도구가 없으면 안내하며 실행하지 않는다. 선택만 바뀌고 단축슬롯 등록/즐겨찾기는 바뀌지 않는다.

보관함·제작대·침대·우물 등은 선택 도구와 관계없이 상호작용한다. 터치 정책에는 recover/lift/lower/place 명령이 없다. 명시적 배치 모드는 기존대로 유지한다. 새 터치·직접 도구 변경·대상 소멸·연결 끊김은 예약을 취소한다. 실제 행동 직전에 대상/도구를 다시 확인하며, 기존 새 정지 입력 ACK→서버 정지→방향 확인→한 번 실행 순서를 유지한다. 서버 권한/중복 actionId/도구 강화/작업 횟수/30Hz 이동 코드는 변경하지 않는다.

## 검증과 배포 정책

v2.8.4 FAST/TARGETED/FULL 워크플로와 선택기를 그대로 유지한다. 이번 변경은 shared/server를 포함하므로 정책상 관련 통합·PostgreSQL·브라우저 검사 범위를 넓히며, 변경 없는 과거 lab/legacy 전체 검사는 실행하지 않는다.

추가 검사는 강우/광량/사건 확률, 시간대 수분 갱신, 모든 작물의 수확 수분, 안전한 터치 정책, 취소/정지 ACK, 실제 Colyseus 다중 접속 동기화·경쟁 수확·방 재개를 포함한다. 기존 브라우저의 암묵적 경작/파종 가정은 실제 행동 버튼으로 바꾸고 시설/자연물은 자동 선택 정책을 검증한다.

Railway 기존 Frontend/Backend/PostgreSQL과 자동 배포를 유지한다. 대기 중인 Check Suites 두 건은 적용하지 않는다. 현 설정은 CI 완료를 기다리는 배포 게이트가 아니므로 CI와 배포 결과를 각각 확인해야 한다. 실제 Android 하드웨어 성능/체감 음량은 이 환경에서 측정하지 않는다.
