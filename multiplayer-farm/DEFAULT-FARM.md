## 자유 공간과 충돌

- 경작 가능 **7,017타일 / 62.30%**. 중앙·남쪽·남서·남동을 비롯한 테두리 안쪽 잔디 평지가 대상이다. 불규칙한 가장자리와 생활권·길을 제외한 형태로, 직사각형 밭 장식을 만들지 않는다.
- 같은 자유 공간에 building/decoration/animal zone을 허용한다. 생활 마당·길·출구·우물 접근·고정 충돌물 주변은 `no-placement`로 보호한다.
- 주요 흙길은 중심 반경 1.8타일, 실제 3–4타일 폭이다. 바깥 1타일 정도의 경작·배치 보호 여유도 둔다.
- 집 벽, 우물, 보관함, 제작대, 벤치, 우편함, 일부 울타리·돌에는 오브젝트 충돌 box를 둔다. 고정 테두리 나무는 작은 줄기만 막는다. 월드 바깥 경계는 Collision chunk로 막고 남쪽 warp 구간은 연다.
- 오브젝트 217개, chunk 48개. 기본 잔디는 sparse 기본값, 변화 지점만 terrain cell을 기록한다. 화면 근처 chunk/오브젝트만 그리는 기존 구조와 editor/game entry 분리를 유지한다.
- terrain: grass, dark_grass, dirt_path, stone_path, gravel. 모든 변형은 고정 seed를 사용한다.
- 기존 집·우물·나무 3종·관목·작은 꽃 장식·돌·벤치·우편함·램프·짧은 울타리를 재사용한다. 생활 마당에 공유 보관함·제작대와 제거 가능한 입문 나무 1개를 둔다. 테두리 나무는 고정 장식이지만 편집기에서 이동·삭제할 수 있다.
- 집 depth는 바닥 선에 맞춰 +96px, 나무는 줄기 기준 y 정렬이다. 화면 전체를 덮는 고정 Upper Decoration을 사용하지 않는다.

## 휴대폰에서 시작·재편집

1. 게임에서 **새 가족 농장**을 만든다. 이미 편집 설계도가 선택돼 있으면 **기본 월드 사용**을 먼저 누른다. 기존 농장은 이어하기로 그대로 유지된다.
2. 집 앞 길 밖의 넓은 잔디를 괭이로 갈고 씨앗을 심는다. 우물은 집 오른쪽이다.
3. `/editor.html`에서 이 맵을 편집할 수 있다. 기기에 이전 초안이 있으면 자동으로 보존·복원된다. 새 기본맵을 열려면 필요시 초안을 JSON 내보내기한 후 **메뉴 → 저장 → 기본 설계도 복원**을 누른다.
4. 편집 → 서버 저장 → 초기 월드 적용 → 새 가족 농장 만들기. 기존 가족 snapshot을 바꾸지 않는다.

## 기존 저장본 보호

저장된 `world.layout`에는 새 기본맵을 병합하거나 덮어쓰지 않는다. snapshot 이전의 오래된 가족은 `legacyLayout()`으로 v2.6 지형을 복원한다. 이는 호환용 고정 데이터이며 새 농장 기본값과 혼용하지 않는다. 인벤토리·돈·퀘스트·작물·가족 데이터는 유지된다. DB schema 변경·reset·새 DB·새 Railway 서비스가 필요하지 않다.
